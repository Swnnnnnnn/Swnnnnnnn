## 🚀 Selected Projects

* **[Stochastic Calculus & Jump Detection](https://github.com/Swnnnnnnn/projet-recherche-calcul-stochastique)** : Complete jump detection pipeline for asset prices using the Lee-Mykland test with bipower variation. 📄 *[Read my Inria research paper on HAL](https://inria.hal.science/hal-05419167)*.
* **[Monte-Carlo Geometry Processing](https://github.com/Swnnnnnnn/Monte-Carlo-Geometry-Processing)** : Solving PDEs directly on complex geometries without volumetric meshing using a Monte Carlo Walk on Spheres (WoS) approach.
* **[Entropy SGLD](https://github.com/Swnnnnnnn/Entropy-SGLD)** : PyTorch implementation of Entropy-SGLD to study its PAC-Bayes generalization properties and resistance to overfitting on image classification tasks.
* **[Time Series Project IIA](https://github.com/Swnnnnnnn/Time_Series_Project_IIA)** : Evaluation of IIA-GCL and IIA-TCL algorithms on real stock market data to capture market non-stationarity and shocks.
* **[Robotics-Project](https://github.com/Swnnnnnnn/Robotics-Project)** : MPC-based humanoid walking control using the Linear Inverted Pendulum Model with ZMP constraints.
